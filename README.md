🏰 Nigel V11.2: The Fortress EditionNigel is a high-performance, standalone Telegram MTProto relay designed to bridge the gap between Telegram, the web, and your cloud storage. Built for efficiency, Nigel bypasses standard bot limitations using the MTProto engine to natively handle files up to 2GB without the overhead of Docker or local API servers.🚀 Key FeaturesNative 2GB Support: Bypasses the 20MB/50MB Bot API restrictions.Sequential Pipeline: Pipes yt-dlp → 7zip to save 50% disk space during transfers.Military-Grade Encryption: AES-256 password-protected .7z archives.Azure Optimized: Tuned for B1s/B2s instances (~50MB RAM usage).Smart Throttling: Intelligent progress updates to avoid Telegram Flood Waits.🛠️ Prerequisites & How to Get Them1. System Dependencies (Linux)Nigel relies on three core binaries. Install them via your terminal:7-Zip: Required for encrypted archiving.sudo apt update && sudo apt install p7zip-full -y
yt-dlp: Required for link processing. We recommend the standalone binary for the latest fixes:sudo wget https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -O /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp
Rclone: Required for cloud uploads.curl https://rclone.org/install.sh | sudo bash
2. Telegram CredentialsYou need three values for your .env file:API_ID & API_HASH: Obtain these from my.telegram.org.Note: If you are unable to generate these due to regional restrictions, the bot is pre-configured to fallback to official Telegram Desktop public keys.BOT_TOKEN: Create a bot via @BotFather and copy the token.ALLOWED_USER_ID: Send /start to @userinfobot to get your numerical ID. Nigel will only respond to this ID.3. Rclone Headless Setup (Google Drive / OneDrive)Since you are likely on a remote VPS (Azure) without a browser, follow this "Headless" flow:On Azure: Run rclone config. Create a new remote (e.g., named drive).When prompted for "Use auto config?", choose n (No).On your LOCAL PC: Install Rclone, open your terminal, and run the command provided by the Azure prompt:rclone authorize "drive" "..."Login: Your local browser will open. Grant permissions.Token: Copy the JSON code from your local terminal and paste it back into your Azure terminal.Verify: Run rclone lsd drive: to ensure it works.⚙️ InstallationClone the Repo:git clone https://github.com/yourusername/nigel.git
cd nigel
Setup Environment:python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
Configure:cp .example.env .env
nano .env
Launch:python bot.py
